# 🕒 Age Calculator

A simple and responsive **Age Calculator** web application built with **HTML, CSS, and JavaScript**.  
Users can enter their date of birth and instantly get their exact age in **years, months, and days**.

---


---

## ✨ Features
- ✔️ Clean and user-friendly interface  
- ✔️ Calculates age in **years, months, and days**  
- ✔️ Real-time age calculation  
- ✔️ Input validation for empty or invalid dates  
- ✔️ Fully responsive design  
- ✔️ Built with pure HTML, CSS, and JavaScript  

---

## 🧰 Technologies Used
- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
